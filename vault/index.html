the whole idea

Everything is markdown in one git repo.

Notes, tasks, transcripts, saved sessions, and the automation's own source code. Agents read it, write it, and ship through it.

how-to · ~10 minutes

One paste gets you a Slack bot.

1api.slack.com/apps → New App → From a manifest → paste →
2Install → two tokens into ~/.vault/slack.env
3/invite the bot to your channel. Done.
{ "display_information": { "name": "vault-bot" },
  "features": { "bot_user":
    { "display_name": "vault-bot" } },
  "oauth_config": { "scopes": {
    "bot":  ["chat:write", "reactions:write",
             "im:write", "im:history"],
    "user": ["channels:history"] } } }

Bot token posts, user token reads. That's the whole trick.

overnight

Long jobs run while I sleep.

  • Sessions live in remote tmux + plan docs in the vault, so disconnects lose nothing and claude --resume picks up mid-thought
  • Several Claude Max accounts, enrolled once: on a usage limit, claude-rotate kills the session, switches account, resumes, and nudges it onward (live as of this morning)

twice daily

Docs that keep themselves current.

  • state-refresh on the work cluster: headless claude -p merges cluster-visible evidence (runs, evals, commits) into state.md + research_log.md
  • Same pattern at home: situational_awareness.md re-synthesized hourly from journal · tasks · calendar · git
  • Sessions read state instead of re-deriving it: the doc is the handoff between yesterday's agent and today's
when a session ends

No conversation is ever lost.

  • A Stop hook saves every session to the vault, plus a one-line index
  • Sessions sync across machines with the vault: the ○ rows in the picker are another machine's, resumable as handoffs
  • claude-resume reopens any of them, any day, on any machine

accounting

What it costs, tracked per agent.

  • token_tracker wraps every claude -p call with a tag, so real token counts land in token_usage.jsonl
  • vault-tokens breaks spend down hourly · daily · all-time; token_monitor alerts when a day or a session crosses a threshold
  • Interactive sessions ride the Max subscriptions, and with the account rotation that side is a flat cost

why it stays boring

What actually keeps it working.
