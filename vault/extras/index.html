claude-vault-starter · extras

14 standalone scripts.

Each one is a single stdlib-only python file. Download the ones your setup uses into ~/.local/bin; PROMPT.md has the cron lines for each.

curl -fsSL https://jeremy-collins.com/vault/extras/vault-doctor -o ~/.local/bin/vault-doctor && chmod +x ~/.local/bin/vault-doctor
calendar-synchourly: your private iCal feed → Calendar.md, next 14 days
journal-prompt11:55pm: one specific question about what actually happened today, from your note + commits + calendar
project-contexthourly: per-repo CLAUDE.local.md (git-excluded) rebuilt from the vault notes, daily-note lines, recent sessions and calendar entries that mention that project; 8 KB cap
refine-prefsweekly: distills corrections you made in archived sessions into coding_prefs.md
reminderreminder add "+30m" "stand up": DM (or log) when due; a per-minute cron line fires them
session-distillweekly: a week of Conversations/ → one Distill/ note: decisions, open threads, things learned, what the next session should know
task-nagger9am / 2pm / 7pm: picks the single task most worth doing right now and nudges you
task-workerhourly: DMs a plan for one unchecked task in Tasks.md; reply "yes" and it does the work and reports back (needs the bridge)
test-fixtest-fix "pytest -x" 3: run any test command; on failure Claude makes bounded, minimal fix attempts
todoist-tasksevery 30 min: new Todoist tasks → Tasks.md, scored I/U/T by Claude (needs your API token)
vault-digest8am: 5-line summary of everything that changed in the vault in the last 24h
vault-doctordaily: broken links, unclosed frontmatter, orphan notes → Meta/vault_doctor.md
vault-organizerdaily: Claude proposes filing loose root notes into your folders; python validates every move, Inbox/ when unsure
vault-tokensvault-tokens 7: per-day Claude Code token usage, from local session logs
